# Pars Dej — طراحی فنی پارس دژ

این نسخه بازطراحی رابط کاربری را دارد و اسکلت صفحات قبلی حفظ شده است.

## تغییرات این نسخه

- بک‌گراند CCTV از فایل اختصاصی `public/service-backgrounds/cctv.webp` استفاده می‌کند.
- فایل قدیمی گرافیک فنی CCTV حذف شده و هیچ ارجاعی به آن باقی نمانده است.
- در هوم‌پیج، بخش خدمات به کارت‌های بزرگ‌تر و شیشه‌ای تبدیل شده است.
- برای هر خدمت یک آیکون مستقل و واضح از مجموعه `cctv-icons` استفاده شده است.
- لوگوی شیشه‌ای پارس دژ در پشت بخش خدمات به صورت الگوی متوسط و قابل‌دیدن قرار گرفته است.
- هنگام Hover روی هر خدمت، لوگو و آیکون همان کارت روشن‌تر، واضح‌تر و برجسته‌تر می‌شوند.
- Cursor سفارشی و نور دنبال‌کننده‌ی موس حفظ شده است.

## اجرا

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.
